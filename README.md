### How I work

- **Ship end-to-end.** I'd rather build a small system that runs than a large one that only compiles. Every featured repo above is something you can clone and run.
- **Structure first.** Clear module boundaries, reproducible setups, and READMEs that explain *why*, not just *what*.
- **Engineering hygiene isn't optional.** Tests, CI, licenses, and version control discipline — even on side projects.
- **Learn in public, claim honestly.** I mark what's done vs. in-progress and I only put skills on this page I can defend in a code review.
